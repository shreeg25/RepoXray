# <h1 align="center"> 🚀 RepoXray: Codebase Architect & Sentinel </h1> <h3 align="center"> Your AI-Powered Documentation & Security Nexus </h3> <p align="center"> In the neon-drenched future, clarity and security are paramount. RepoXray isn't just another program; it's your digital architect and sentinel, a robust AI orchestrator designed to tame the chaos of complex codebases. Forged in the crucible of the Epoch X Nasiko Hackathon, RepoXray transcends basic LLM wrappers, transforming raw, sprawling code into pristine, insightful documentation and critical security audits. It's the silent partner that ensures your projects are not only well-understood but also fortified against the unseen threats lurking in the digital ether. </p> <br/> <h2> 🎯 PROJECT PURPOSE </h2> <p> RepoXray serves as an indispensable tool for developers, project managers, and security professionals navigating the intricate landscapes of modern software development. It automates the arduous and error-prone process of documentation and initial security assessment, providing immediate, high-quality insights into any codebase. By leveraging advanced AI, RepoXray solves the critical problem of outdated or missing documentation, allowing teams to quickly onboard new members, understand legacy systems, and proactively identify security vulnerabilities. It delivers a comprehensive overview of project purpose, architecture, and potential weak points, acting as a crucial bridge between code complexity and human comprehension. </p> <h2> ✨ CORE FEATURES </h2> - **AI-Powered Documentation Generation:** Analyzes codebase structure and content to autonomously generate a professional, detailed `README.md`, encapsulating project purpose, features, and architectural overview using Google Gemini's generative AI. - **Integrated Security Posture Audit:** Simultaneously scans the code for potential security vulnerabilities and considerations, generating a `SECURITY_AUDIT.md` that identifies weaknesses and suggests remediations. - **Modular Agent-Based Architecture:** Utilizes a `ReadmeAgent` to orchestrate the entire documentation and audit generation process, employing separate 'map' and 'reduce' models for efficient and scalable LLM interaction. - **Intelligent File Filtering:** Employs a `ProjectReader` to intelligently filter and include only relevant source code files, ignoring common binaries, development-related directories (e.g., .git, node_modules, venv), and adhering to `.gitignore` rules, thereby optimizing LLM token usage. - **Multi-threaded File Processing:** Enhances performance by concurrently reading and processing multiple files using a `ThreadPoolExecutor`, speeding up large codebase analysis. - **Robust LLM API Interaction:** Implements `tenacity` for exponential backoff and retry logic when communicating with the Google Gemini API, ensuring resilience against transient network issues or API rate limits. - **Flexible Deployment Options:** Provides both a command-line interface (CLI) for direct execution and a Streamlit-based web user interface for interactive analysis and real-time feedback. - **Centralized Configuration Management:** Manages critical settings such as the Google API key and AI model names via environment variables through a dedicated `Config` class, promoting secure credential handling. <h2> 🛠️ TECH STACK </h2> - If not present, install `google-generativeai`, `python-dotenv`, `streamlit`, `tenacity`). 4.  **Configure Google API Key:** Create a `.env` file in the project root directory and add your Google Gemini API key: ``` .env GOOGLE_API_KEY="YOUR_GEMINI_API_KEY" ``` 5.  **Run the CLI Tool:** To analyze the current directory: ```bash python -m src.main ``` To analyze a specific directory: ```bash python -m src.main ./path/to/your/project ``` 6.  **Run the Streamlit UI:** ```bash streamlit run src/ui.py ``` Open the URL displayed in your terminal (usually `http://localhost:8501`) in your web browser. Follow the instructions on the page to upload or specify a target directory for analysis.
